# Modify an approved algorithm rule

Clarify the general current rule and proposed change before source edits. Identify owner, exact chronology, equality, source selection, identity/provenance and lifecycle implications. Define both directional forms, implement only within authorized scope, run protected and independent directional validation, and synchronize both current References and embedded source.
