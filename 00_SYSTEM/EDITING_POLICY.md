# Current editing policy

Preserve current concept IDs only when meaning remains the same. Rewrite source-derived knowledge after reviewing its current owner, then rebuild all indexes; never edit an index to change a rule. Exact Source and Reference snapshots are copied from current files and verified by SHA-256 and bytes, never manually rewritten.

Production changes require explicit authorization in the current task. This Phase-1 audit keeps Engine Source and both directional References read-only; demonstrated documentation/retrieval defects authorize only the requested Vault/Plugin repairs. Reference/documentation/tooling synchronization follows the current task; preserve unrelated work. Preserve pre-existing dirty work and Git metadata. Remote push requires explicit current-task authorization. Every Graphify execution requires its own explicit user authorization; the generic knowledge indexes here are generated by the Vault indexer.

All technical authored notes, tooling, identifiers, messages and tests are English. Do not encode timestamps, market symbols, OHLC fingerprints or fixture identities as production algorithm branches. Material semantic ambiguity requires investigation and a precise question.

This Vault retains current knowledge only. Obsolete rules, source snapshots, references, decisions, data and fixture assertions are removed, rather than moved into a history folder. Future Data and Fixture additions require explicit user inputs and their own integrity/semantic review.
